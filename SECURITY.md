# VICTUBYTE Security Policy

## Overview

Security is an important part of VICTUBYTE.

We appreciate responsible reports that help identify vulnerabilities, protect
contributors and improve the security of the project.

## Supported Versions

Security fixes are prioritized for the latest development version and the latest
officially published release.

Older experimental builds may no longer receive security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately
to the project maintainer.

Do not publish sensitive technical details in public Issues before the problem
has been investigated.

You can use GitHub's private vulnerability reporting feature if it is enabled
for this repository.

Repository:

https://github.com/joao01020/victubyte

## What to Report

Examples include:

- Exposed credentials or secrets.
- Unsafe handling of local files.
- Unexpected execution of external commands.
- Vulnerabilities in external integrations.
- Unauthorized access to project services.
- Problems affecting the integrity of game data.
- Security issues involving included dependencies.

## Responsible Disclosure

Please:

1. Provide a clear description of the issue.
2. Include steps to reproduce it safely.
3. Avoid accessing or modifying data belonging to others.
4. Do not exploit the issue beyond what is necessary to demonstrate it.
5. Allow reasonable time for investigation and remediation before public
   disclosure.

## Educational Gameplay

VICTUBYTE includes fictional cybersecurity challenges and simulated hacking
mechanics.

These mechanics are intended for educational gameplay in controlled
environments.

Security reports must distinguish between intended fictional game behavior and
actual vulnerabilities affecting the project or its users.

## Scope

This policy covers the VICTUBYTE source code, official releases and
project-controlled infrastructure.

Third-party services and dependencies remain subject to their respective
security policies.

## Thank You

Responsible security research helps make VICTUBYTE safer for everyone.
