# VICTUBYTE Code of Conduct

## Our Commitment

We want VICTUBYTE to be a welcoming, respectful and collaborative community.

Everyone participating in the project is expected to help create a positive
environment regardless of experience level, background or contribution type.

## Expected Behavior

Community members are expected to:

- Be respectful and considerate.
- Communicate constructively.
- Welcome different perspectives and experiences.
- Provide helpful and respectful feedback.
- Respect other contributors' work and time.
- Accept constructive criticism.
- Focus discussions on improving the project.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination or personal attacks.
- Insults, threats or intimidation.
- Publishing private information without permission.
- Deliberate disruption of discussions.
- Spam or malicious contributions.
- Deliberately misleading or impersonating other contributors.
- Any behavior that creates an unsafe or hostile environment.

## Reporting Problems

If you experience or witness unacceptable behavior, contact the project
maintainer through the official GitHub repository.

Reports will be reviewed and handled as appropriately as possible.

## Enforcement

Depending on the severity of the situation, actions may include:

1. A warning.
2. Removal of inappropriate content.
3. Temporary restriction from community participation.
4. Permanent exclusion from project spaces.

The project maintainer is responsible for enforcing these guidelines.

## Scope

This Code of Conduct applies to:

- GitHub Issues.
- Pull Requests.
- Discussions.
- Project-related community spaces.
- Other spaces where individuals represent the VICTUBYTE project.

## Final Note

We are building more than a game. We are building a community around creativity,
technology, education and collaboration.

Be respectful. Be curious. Keep creating.
